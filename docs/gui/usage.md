# GUI 使用说明

从 [GitHub Releases](https://github.com/Virace/lol_extract_voice/releases/latest) 下载 GUI 程序，
打开后跟随首次使用引导设置游戏目录和输出目录。也可以按 [README](../../README.md#从仓库运行)
中的步骤从仓库启动。

## 选择和处理音频

首次启动或切换游戏、输出目录时，界面会先准备英雄和地图列表。列表可用后就能选择对象，
解包和映射需要的数据会在任务开始时按所选范围准备，已有数据会复用。

英雄、地图分别通过输入框左侧的下拉选择“不处理 / 全部 / 指定 ID”，初次打开时均为“不处理”。
只有“指定 ID”允许输入，支持中英文逗号混用，例如 `1，103,555`。指定模式留空不会变成全部；
可以单独选择全部英雄而不处理地图。“全部”只包含该类普通实体，特殊内容仍需明确选择。

在实体总览点击“发送到执行中心”会同步选择并跳转页面，不会立即执行或打开确认窗口。
默认只处理 VO 语音，需要音效和音乐时可切换为全部类型。按需勾选解包、WAV 转码和事件映射后，
点击“创建任务”，核对只读窗口中的名字、ID 和参数。点击“确认”才开始执行；“返回修改”关闭窗口，
保留当前表单。

未找到的 ID 会在窗口顶部提示，并列入滚动清单。确认后只执行有效范围，跳过记录保留在结果详情；
全部无效时不能执行。资源文件缺失和解析失败仍会单独报告，不会当作未知 ID 静默跳过。

如果希望后面的任务更快开始，可以在“全局设置 → 基础设置”中开启“提前准备数据”。
它会提前补齐普通英雄、地图的资源和事件数据，默认关闭，不会每次强制重建已有数据。
准备失败时，界面会保留原因，并提供重试或重新生成数据的入口。

## 查找、试听和导出

实体总览按“英雄 / 地图 / 特殊内容”分类，`A` 表示已有音频，`M` 表示已有事件映射。
有映射时可以按事件查找；没有映射时，仍可在“全部音频”里试听、导出和打开文件位置。
同一音频 ID 出现在不同路径时，会分别显示。

大型地图首次打开“全部音频”需要加载，列表上方会显示进度。切换页面后仍会继续准备，
返回同一实体时可以复用已经加载的结果。

点击“选择导出”，可以按目录、事件节点或单条音频选择已有 WEM，再批量导出 WAV。
支持全选、排除、清空、撤销和仅看已选；确认时请核对范围和覆盖选项。
选择只针对当前实体，不会跨实体累积，也不会自动解包缺失文件。

皮肤和炫彩会按实际资源共享关系处理：完全继承的事件不重复展开，变化的事件保留音频列表，
共享 WEM 可能只在来源皮肤下保存。全部音频展示的是实际文件；旧版产生的重复文件不会自动删除。

**编辑前先导出或复制到资源库外。** 库内音频可能使用硬链接共享内容，直接编辑会影响其他引用。
硬链接不可用时程序会报错并保留原文件。目录组织、内容共享和旧目录迁移见
[资源库说明](../api/library_api.md)。

## 特殊内容与本地资源包

“经典召唤师峡谷”等结构化特殊内容直接来自当前客户端，选中后可发送到执行中心处理。
它们不会在普通英雄列表中重复出现。

要查找额外资源包，在实体总览搜索栏旁的更多菜单中选择“扫描本地 WAD…”，
选取当前游戏 `Game/DATA/FINAL` 下需要的 `.wad.client`。程序只扫描所选文件，
扫描后仍需创建解包任务。

资源包列表会显示来源、发现状态和音频、映射状态。解包结果位于
`audios/<version>/<region>/resource_packs/`，映射位于 `hashes/<version>/<region>/resource_packs/`。
资源包暂不支持执行中心的整包 WAV 转码；已有 WEM 可以在总览中试听和选择导出。

## 查看结果与处理失败

任务完成后，可以从通知打开结果详情；关闭通知后，仍能在执行中心点“查看本次结果”。
失败重试前会显示实际处理范围，请根据提示确认是文件、容器、实体还是整个阶段。

转码失败默认最多尝试 3 次，使用原来的后端和参数。仍然失败时会保留诊断信息，
处理原因后可以重新创建任务。失败转码不会作为已完成文件供下次复用。

目前一次执行一个任务，没有多任务队列和暂停续跑功能。

## 配置与旧数据

GUI 自动保存设置：打包程序使用 EXE 同目录的 `lol-audio-unpack.ini`，
从仓库运行时使用当前目录的同名文件。手动编辑可参考
[示例配置](../../config/lol-audio-unpack.example.ini) 和 [配置 API](../api/config_api.md)。

启动时会迁移旧版没有语言层的输出，保留已有音频、映射、元数据和 WAV，无需重新解包。
迁移成功后使用新目录；失败时保留未处理完的文件并阻止新任务，处理原因后重新启动可继续。
内部数据格式和旧 YAML/JSON 转换方法见 [数据格式说明](../api/README.md#4-数据格式约定)。
