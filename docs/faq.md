# 常见问题

## 下载与启动

### 界面版和控制台版应该下载哪个？

想通过界面选择、试听和导出，下载界面版；需要批量处理或编写脚本，下载控制台版。
两者都在 [Release 页面](https://github.com/Virace/lol_extract_voice/releases/latest)，Windows x64 独立包无需安装 Python。

<a id="platforms"></a>

### Linux、macOS 和其他 UNIX 系统怎么使用？

发布页目前只提供 Windows 打包版。其他系统可克隆或下载仓库源码，安装依赖后直接运行，无需打包。
具体命令见 [从仓库运行](../README.md#从仓库运行)，界面与控制台均有源码入口。

| 系统 | 使用方式 |
| --- | --- |
| Linux，如 Ubuntu、Debian、Fedora | 准备 Python 3.10+ 和 uv，按源码命令安装并运行 |
| macOS | 使用相同源码入口；实际客户端目录与完整流程尚未实测 |
| 其他 UNIX 系统 | 按源码方式使用，需满足 Python 版本并能安装项目依赖 |

游戏文件可以从其他机器或外部工具准备，只要符合 [本地游戏目录](api/prepared_source.md) 要求。
若需要独立程序，也可自行在目标系统打包；当前提供的打包流程面向 Windows。

### 游戏目录应该选到哪一层？

选择包含 `Game/` 文件夹的客户端根目录，不要直接选 `Game/DATA/FINAL`。
本地客户端与外部准备目录的输入要求见 [本地数据源说明](api/prepared_source.md)。

## 界面使用

### 英雄或地图列表没有出现怎么办？

先等待准备完成。若界面提示失败，检查游戏目录是否正确、输出目录是否可写，再按提示重试。
仍然失败时保留错误提示和日志。

### 为什么界面只有“仅 VO”和“全部类型”？

界面提供的是简化选项，没有逐项展开音效和音乐分组。需要特殊音效、背景音乐或不确定类型的音频时，
选“全部类型”。具体分组见 [音频类型](audio-and-output.md#audio-types)。

### 有音频，为什么看不到事件？

在执行中心为这个英雄或地图勾选“事件映射”，处理完成后再查看。
没有映射时，可以先在“全部音频”中试听和导出。

## 音频文件与输出

### 处理完成后，WAV 在哪里？

界面、控制台和源码运行的输出规则一致。WAV 在输出目录的 `wavs/`；
手动导出或独立转码使用指定目录。
只解包不会生成 WAV。完整位置见 [输出目录](audio-and-output.md#output-folders)。

### 为什么一些皮肤没有独立的一整套音频？

皮肤可能沿用其他皮肤的语音，共享文件不一定在每个皮肤目录中重复保存。
可以从事件列表查找对应音频；资源共享说明见 [技术文档](api/library_api.md)。

### 可以直接编辑输出目录里的 WEM 吗？

请先导出 WAV，或复制到输出目录之外再编辑。部分原始文件共享内容，直接修改可能影响其他引用。

## 控制台使用

### 双击控制台程序后窗口关闭怎么办？

控制台需要在终端中带参数运行。打开程序所在目录的 PowerShell，先执行：

```powershell
.\LolAudioUnpack-CLI.exe --help
```

程序文件名带版本号时，用实际文件名替换。常用命令见 [控制台使用说明](cli-package.md)。

### 为什么配置文件不能和命令参数一起用？

`-c` 使用完整配置文件，动作和参数都从文件读取。选择下面一种方式即可：

**使用配置文件：**

```powershell
.\LolAudioUnpack-CLI.exe -c .\任务.ini
```

**使用命令参数：**

```powershell
.\LolAudioUnpack-CLI.exe update extract --champions Annie --game-path "D:/Games/英雄联盟"
```

## 失败与排错

### 任务失败时，需要提供哪些信息？

记录程序版本、操作步骤、对象 ID、完整错误提示，以及本次日志；控制台日志在输出目录的 `logs/` 中。
分享前检查日志是否包含个人路径或其他不希望公开的信息。
界面可从任务通知或执行中心的“查看本次结果”查看失败原因；先修正原因，再核对范围重试。
