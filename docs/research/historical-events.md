# 事件名与事件范围：历史版本实测

研究日期：2026-10-12。安妮、龙女、乌迪尔，9 个客户端版本，54 个 WAD；语音语言为 `zh_CN`。

**事件名适合缩小候选范围，但不能作为永远不变的范围 ID。** 实测同时存在“原始内容相同、事件改名”和
“事件名与 Event ID 不变、候选音频数量改变”。同年度较远、相邻的两段样本均稳定，不能据此保证其他补丁。
Sound ID 与 WEM ID 的调查见 [音频身份实测](historical-wem.md#sound-id-study)。

## 事件名、Event ID 与音频是什么关系

本次事件名是 BIN 中的真实文本，例如 `Play_vo_Annie_MoveOrder2D`，不是工具生成的中文描述。
BNK HIRC 中的 Event 记录保存数字对象 ID；它引用 Action，播放 Action 再指向随机、切换等容器与 Sound，
Sound 的文件源引用 WEM。WEM 既可能在 WPK，也可能在 BNK DIDX/DATA 中。

[Wwise 官方说明](https://www.audiokinetic.com/zh/public-library/2024.1.9_8920/index.html?source=Help&id=managing_media_asset_ids)
区分按名称生成的 ShortID、Sound 等对象身份与媒体 MediaID。本次对 BIN 原始名称做小写 ASCII 的 FNV-1 计算，
与全部 1,908 条实际 Event ID 对上；1,441 对同名跨版本事件的 Event ID 全部相同。
没有发现不同小写事件名的 ID 冲突，也没有发现一个样本的不同 VO 分组共用同一事件名。
这些是样本结论，不构成全游戏、所有语言或未来 32 位 ID 无冲突的保证。

**Event ID 的稳定取决于名称，不能证明事件下的声音稳定。** 也不是每个事件都直接播放音频：
25 条 `Udyr_Switch_*` 是 `CAkActionSetSwitch` 控制事件，`idExt` 表示 Switch 状态值，不是缺失的 Sound。
另有 Silence 源插件可生成声音，不能将其 sourceID 当作 WEM 文件名。

## 内容相同，事件名也会改

安妮 Base VO，10.15 → 11.15，实际 BNK 的移动事件与攻击事件都改名。下列数字为十进制：

| 旧事件名 | 新事件名 | Event ID | WEM 数 | 共有唯一原始内容 |
| --- | --- | --- | ---: | ---: |
| `Play_vo_Annie_MoveOrder2D` | `Play_vo_Annie_Move2DStandard` | `2820323503` → `282358042` | 8 → 8 | 8 |
| `Play_vo_Annie_AttackChampion2D` | `Play_vo_Annie_Attack2DGeneral` | `1252715427` → `4077603490` | 9 → 9 | 9 |

移动事件的实际 WEM ID 为：

```text
10.15: 37314378, 39458415, 154069994, 465408942,
       619845573, 689053895, 738205542, 801921796
11.15: 36642736, 543764059, 605038973, 726325637,
       809620652, 828469072, 1933305856, 1961652472
```

两组的 8 份唯一 WEM 原始内容相同；ID 列表按数字排序，**不能按列表位置逐句配对**。
该区间安妮没有已知 VGU，整体中文 WAD 的 47 份唯一内容也逐字节一致。名称变化已经足以否定永久范围 ID。

龙女 Base VO 与 Skin08 VO，11.15 → 12.15 各有 4 个同内容改名候选，包含移动、攻击及龙形态对应事件。
例如基础移动从 `Play_vo_Shyvana_MoveOrder2D` / `905856550` 改为
`Play_vo_Shyvana_Move2DStandard` / `422613721`，共有 9 份原始内容。
`rename_candidates` 按非空内容集合完全相同产生；这是迁移候选依据，没有自动断言触发条件和游戏语义也完全相同。

## 同名事件的音频数量和集合也会改变

乌迪尔 Skin03 VO，10.15 → 11.15：

| 事件名 | 两版共同 Event ID | Sound 数 | WEM 数 | 唯一内容数 | 共有内容 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `Play_vo_SpiritUdyrHuman_UdyrBearAttack_OnCast` | `1589454722` | 4 → 3 | 4 → 3 | 4 → 3 | 3 |
| `Play_vo_SpiritUdyrHuman_Joke3D` | `3587106897` | 1 → 1 | 0 → 1 | 0 → 1 | 0 |

第一行实际 WEM ID：

```text
10.15: 45794605, 56086629, 536893220, 741289190
11.15: 623757691, 678010763, 1691475006
```

第二行旧版本引用 Silence 源插件，后续版本引用实际 WEM；旧的 0 不表示解析漏文件。
乌迪尔 VGU 在之后的 12.16，因此本区间没有跨过该重做。
同一份减少的媒体还影响其他姿态下的 BearAttack 事件：该分组共 6 条同名事件的 WEM 数量改变，不能视为 6 次独立台词修改。

数量不变也不足以确认内容相同。安妮 Base VO 14.15 → 15.15 的 12 个事件名称、Event ID、WEM 数量均不变，
12 个事件的原始内容集合全部改变。龙女 Base VO 14.15 → 15.15 从 25 个事件变为 24 个，移除
`Play_vo_Shyvana_ShyvanaTransformLeap_OnBuffDeactivate`，仍同名的事件中有 20 个内容集合改变。
这些字节差异没有经过解码或试听，不能直接解释为台词改写。

## 后续如何利用事件范围

可以按 **实体、VO 分组、语言、事件名** 缩小候选范围，同时保存版本、原始名称、Event ID、Sound ID、WEM ID 与内容摘要的关联。
名称和 Event ID 用作版本内检索信息；为跨版本改名保留经确认的别名关系，不直接覆盖旧记录。
皮肤共享 VO、同一媒体被多个事件引用、状态控制事件和重做区间都需要保留其来源。

翻译或语音转文本可以先在相同事件或已确认别名范围中匹配 WEM 摘要，复用字节完全相同内容的结果。
同名事件新增或减少候选、改名、原始字节变化时，分别保留待确认项。若要识别重编码后相同的声音，还需解码后的比对或人工确认；
本次没有建立永久台词 ID，也没有修改产品索引。现有按内容摘要存一份 WEM 的做法仍然必要。

## 独立核对与适用边界

1. 核对 WAD 摘要，提取 BIN、BNK、WPK 和实际 WEM；WPK 原始偏移表与提取入口交叉验证，BNK 检查 DIDX/DATA。
2. BIN 的结构化名称必须存在于原始字节中，再计算名称 ID 并与实际 BNK Event 关联。过期声明保留在 `unbound_declarations`。
3. 在同一英雄、语言的输入内，以 BIN 声明的 bank 名称 hash 匹配唯一 BKHD Bank ID，记录声明路径、WAD 条目键及 bank 摘要。
   这是研究脚本的定位步骤，没有把它当作所有版本路径解析或产品完整 binding 的验收。
4. 固定 wwiser 提交导出 96 个中文 VO BNK 的原始 XML，直接读取 Event、Action、Children、Sound 字段；
   与 NativeHIRC 的可达 Sound/WEM 候选集合比较。公共脚本复跑复用这些已核验 XML，并校验其来源与自身摘要。
5. 重新计算实际 BIN、BNK、WEM 摘要，记录全部对象 ID 与内容集合；重做比较保留数据但排除出非重做结论。

共 1,908 条 Event，未命名、Native 候选集合差异、缺失媒体、未知可达引用均为 0，另有 25 条控制事件。
完整比较为 42 个 VO 分组版本对、1,441 行同名事件；非重做部分 1,421 行。
这是结构上可达的全部候选，未验证随机权重、条件组合、触发先后或单次播放结果，数量不能直接当作不同台词数。
没有地图、其他语言或全部英雄样本，也没有测完整补丁序列。产品源码和依赖未变，未执行无关产品 pytest。
