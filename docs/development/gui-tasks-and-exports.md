# 界面任务与导出规则

本文供维护者核对界面行为。用户操作见 [界面使用说明](../gui/usage.md)，目录与索引合同见
[资源库 API](../api/library_api.md)。

## 任务选择与确认

- 英雄、地图分别选择范围，初始均为“不处理”；“全部”仅覆盖该类普通实体，特殊内容需显式选择。
- “指定 ID”支持中英文逗号，留空不转为全部；未找到的 ID 在确认窗口顶部提示并列入清单。
- 界面只处理有效对象，跳过记录保留在结果详情中；全部无效时不能执行。资源缺失和解析失败另行报告。
  控制台未知 ID 的退出规则见 [控制台参数参考](../api/cli_api.md)。
- “发送到执行中心”同步选择并跳转，不执行任务或打开确认窗口。
- 确认窗口中的名字、ID 和参数只读；“确认”开始执行，“返回修改”关闭窗口并保留表单。

任务创建时冻结目录与参数设置，后续开关变更不改写已有任务。转码默认使用 16 位 PCM，
其他采样格式与自动模式见 [WAV 参数](../api/cli_api.md#wav-options)。

## 准备与失败恢复

启动或切换游戏、输出目录时先准备英雄、地图列表；用户任务按选择范围准备资源与事件数据并复用已有结果。
“提前准备数据”默认关闭，开启后预先补齐普通英雄和地图的数据，不强制重建已有数据。
失败保留原因，并提供重试或重新生成入口。完整状态机与进度边界见
[界面基础目录与按需数据准备](../gui/shared_entity_data_refresh.md)。

转码默认最多尝试 3 次，保持原后端与参数；耗尽次数后保留诊断。失败文件不作为成功产物复用。
结果通知与执行中心均可打开本次结果；失败重试前展示文件、容器、实体或阶段的实际范围。

## 导出布局

批量多选和右键导出节点使用额外 WAV 根目录，保留版本、语言和完整实体路径，不额外嵌套 `wavs/`。
单条“另存为”使用指定文件位置。WAV 镜像实际 WEM 路径，保留按音频类型分组后的层位置。

| 设置 | 影响 |
| --- | --- |
| 按音频类型分组 | 决定新解包 WEM 的 VO / SFX / MUSIC 层位置，WAV 跟随实际路径 |

默认输出为 `wavs/<版本>/<语言>/...`，手动批量导出使用所选根目录。

## 浏览、共享与旧数据

同一音频 ID 在不同路径中分别显示。大型地图的全部音频按需加载，切页后继续准备，返回时复用已加载结果。
完全继承的皮肤事件不重复展开，变化事件保留音频列表；共享 WEM 可能仅在来源皮肤下保存。
全部音频展示实际文件，不自动删除旧版重复文件。

WEM 硬链接引用同一份内容，编辑前必须导出独立副本或复制到库外；不支持硬链接时明确失败并保留原文件。
已发布旧目录在启动时迁移，保留音频、映射、元数据与 WAV。迁移失败时保留未处理完的文件并阻止新任务，
处理原因后重启继续。持久化、迁移与恢复细节见 [资源库 API](../api/library_api.md)。
