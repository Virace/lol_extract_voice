# 音频文件与输出目录

界面版本、控制台版本和源码运行使用同一套音频分类与输出规则。

<a id="audio-types"></a>

## 音频类型

当前按以下三组筛选音频；游戏事件和资源类别还有更细的划分。

| 分组 | 内容 |
| --- | --- |
| `VO` | 英雄语音、播报语音等 |
| `SFX` | 技能、装备、界面提示等音效 |
| `MUSIC` | 背景音乐等 |

选择方法见 [界面操作](gui/usage.md#audio-types) 或 [控制台筛选参数](cli-package.md#audio-types)。

<a id="output-folders"></a>

## 文件保存在哪里

文件保存在你设置的输出目录中。**输出目录、语言和参数相同时，两种版本的目录结构完全一致。**

| 结果 | 输出目录下的位置 |
| --- | --- |
| 原始 WEM 音频 | `audios/<版本>/<语言>/...` |
| 普通 WAV | `wavs/<版本>/<语言>/...` |
| 按事件分类的 WAV | `wavs_by_event/<版本>/<语言>/...` |
| 事件映射 | `hashes/<版本>/<语言>/...` |
| 日志 | `logs/` |

只执行解包会生成 WEM；需要 WAV 时启用音频转码。手动导出或独立文件转码保存到指定的目标目录。

“按事件分类输出”默认关闭，需要同版本、同语言的可用映射。没有可用映射时保留普通目录；
有映射但未关联事件的音频放入“未关联事件”。

## 文件共享与备份

库内字节完全相同的 WEM 只存一份数据，多个版本或皮肤通过索引和硬链接复用。独立导出的文件另行保存。

> **编辑前先导出或复制到输出目录之外。** 备份整个资源库时，请保留完整输出目录。

目录共享、索引和迁移的技术细节见 [资源库 API](api/library_api.md)。
